## Módulos del sistema
-  **Punto de Venta** — Toma de pedidos en tiempo real
-  **Gestión de Pedidos** — Flujo pendiente → entregado
-  **Catálogos** — CRUD de productos, empleados, clientes y promociones
-  **Dashboard** — Reportes y KPIs por sucursal

## Stack tecnológico
HTML / CSS / JavaScript · Node.js + Express · SQL Server · Stored Procedures

## Base de datos
El archivo `tacosoft_database_Sonia&Pedro.sql` contiene:
- 8 tablas con relaciones y constraints
- Datos de prueba (4 sucursales, 20 productos, 13 empleados, 30 pedidos)
- 13 procedimientos almacenados con TRY/CATCH y transacciones
- 3 vistas para reportes
